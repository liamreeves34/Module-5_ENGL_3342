For Module 2, I proposed and wrote a 38-page instruction manual that walks a Python programmer through turning a trained PyTorch digit classifier into a web service: wrapping it in a FastAPI app, packaging it with Docker, and running it on Windows 11 through WSL2.
The hardest part was deciding who the reader was. My approved proposal assumed scikit-learn experience, but the model I actually built used PyTorch, so I wrote a memo changing the prerequisites instead of quietly letting the manual drift away from its audience. Testing was humbling too. A peer finished all three phases in about 45 minutes, but on Ubuntu, which meant the Windows setup steps were still untested.
The choice that worked best was structure. Each of the three phases ends by sending the same image to the predictor, so when something breaks, the reader knows the newest layer caused it. I also placed every caution notice directly before the step it concerns, where a reader actually needs it.
