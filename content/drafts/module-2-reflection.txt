For Module 2, I proposed and wrote a 38-page instruction manual that walks a Python programmer (already familiar with PyTorch and training neural networks) through turning a trained PyTorch digit classifier into a web service by wrapping it in a FastAPI app, packaging it with Docker, and then running it on Windows 11 through WSL2.
The hardest part was deciding who the intended audience was. My approved proposal assumed the user would be familiar with scikit-learn, but the model I actually built used PyTorch, so I wrote a memo changing the prerequisites so the manual could actually relate to the intended audience.
I think the choice that was most helpful was structure. Each of the three phases ended by sending the same image to the digit predictor. That way, if something were to break, the reader would know it is the newest addition to their code that caused the issue.
